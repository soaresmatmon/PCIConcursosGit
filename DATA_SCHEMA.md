# Data Schema Manual: PCI Concursos Tracker

This document provides a comprehensive blueprint of the data schemas, relational models, and column metrics utilized within the automated data sync system.

## 🗂️ Worksheet Architecture Overview

The system orchestrates data transactions across a single localized workbook containing five structurally distinct spreadsheets/tabs:

1. **`concursos`**: The primary operational ledger containing active, validated civil service opportunities within target distance limits.
2. **`concursos_expirados`**: A historical records archive tracking legacy exam notices that have surpassed their registration deadlines.
3. **`geocodes_cache`**: A persistent key-value lookup registry caching geo-coordinates (`lat`, `lon`) for resolved municipalities.
4. **`municipios_ref`**: A static reference dataset containing the official geolocations and IBGE organizational tracking IDs of all standard Brazilian municipalities.
5. **`logs`**: System operational telemetry recording process metrics, write loops, and database adjustments.
